# subspace-site

The one-page website for JS8 / JTTY Subspace Edition, hosted on Vercel.

- `index.html` is the whole site (no build step).
- Screenshots load from the [Subspace-Edition](https://github.com/avantol/Subspace-Edition) repo.
- Every push to `main` redeploys.

Downloads: https://github.com/avantol/Subspace-Edition/releases/latest
